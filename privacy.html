Privacy policy

Last updated: October 9, 2026.

Planner is a personal app used only by its owner.

What it accesses

With the owner's consent, Planner reads and writes tasks in a single Google Tasks list named "Planner". It does not access any other list or any other Google data.

How the data is used and stored

Tasks are used only to plan the owner's own work. The access token and the planning state (goals, places, settings) are kept on the owner's private server. Nothing is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time from Google Account permissions.
